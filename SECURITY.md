# Security

The plugin reads your Claude Code login and, if you set one up, a Claude Console Admin API key. It never writes, refreshes, logs or shares them, and sends them only to `api.anthropic.com`.

If you find a way it could leak or misuse either of them, or any other security problem, please email **elgato@rivo.agency** instead of opening a public issue. We'll answer within a few days and credit you in the release notes if you like.

Security fixes go into the latest release only.
